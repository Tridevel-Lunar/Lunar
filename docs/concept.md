# LUNAR — สาระสำคัญของโครงการ

## วิสัยทัศน์

**Lunar** คือแพลตฟอร์มการเรียนรู้เกี่ยวกับเทคโนโลยีอวกาศ ที่จะเปลี่ยนสิ่งที่ดูเป็นเรื่องไกลตัวและยากอย่าง "อวกาศ" ให้กลายเป็นเรื่องที่จับต้องได้ จนเกิดแรงบันดาลใจและมองเห็นภาพการนำไปประยุกต์ใช้จริงได้มากขึ้นในอนาคตสำหรับประเทศไทย

อวกาศไม่ใช่เรื่องที่อยู่ในจินตนากิอย่างเดียวอีกต่อไป — สิ่งที่กำลังจะเกิดขึ้นต่อไปคือ **เศรษฐกิจอวกาศ** ที่เราสามารถสร้างเทคโนโลยีมาใช้ให้เกิดประโยชน์ได้ ตัวอย่างเช่น การใช้เชน์ประเทศไทยในด้านการเกษตร: นำภาพถ่ายจากดาวเทียมมาวิเคราะห์พื้นที่การเกษตร เพื่อประเมินคุณภาพและจำนวนผลผลิต วางแผนเก็บเกี่ยว หรือสร้างระบบเกษตรอัจฉริยะ

เทคโนโลยีอวกาศสามารถสร้างคุณค่าประโยชน์ในด้านต่าง ๆ ได้อีกมากมาย โดยเฉพาะการนำมาประกอบจากองค์ความรู้เล็ก ๆ ที่เป็น "จิ๊กซอว์" จนเกิดเป็นนวัตกรรมที่มีลูกค้ามหาศาล

Lunar จึงเกิดขึ้นเพื่อ **กระตุ้นให้ผู้คนหันมาสนใจด้านอวกาศมากขึ้น** — นักเรียน นักศึกษา บุคคลทั่วไป และสถาบันการศึกษา สามารถเข้าถึงการเรียนรู้ที่มีคุณภาพได้ง่ายและทั่วถึง

## ฟีเจอร์หลัก 3 ส่วน

> รายละเอียดฟังก์ชันระดับโปรแกรม (Input/Output, กิจกรรมแต่ละด้าน, Arena blocks, LAIKA): **[functional-spec.md](functional-spec.md)**

### 1. Space — เรียนรู้เริ่มต้น (Learn)

ฟีเจอร์แรกสำหรับผู้เรียน ปูพื้นฐาน concept เพื่อสร้างดาวเทียมได้ในขั้นแรก มุ่งเน้นรูปแบบการสอนที่น่าสนใจและสวยงาม แบ่งเป็น **4 หัวข้อหลัก**:

| หัวข้อ | รายละเอียด |
|--------|------------|
| **3D Model** | จำลองโครงสร้างกายภาพภายนอกและ Internal Layout ของ CubeSat 1U |
| **Embedded System** | สถาปัตยกรรม OBC/EPS — การรับส่งกระแสไฟและการไหลของข้อมูล/สัญญาณระหว่างชิ้นส่วน |
| **Physics** | คำนวณและจำลองเงื่อนไขตามกฎธรรมชาติในอวกาศ เช่น กลศาสตร์วงโคจรต่ำ (LEO), Power Budget ช่วง Eclipse |
| **Programming** | สร้างตรรกะซอฟต์แวร์และ Autopilot Logic — เรียนผ่านบล็อกคำสั่งเพื่อคุมฮาร์ดแวร์ฝังตัวให้ปฏิบัติภารกิจภายใต้กฎฟิสิกส์อวกาศ |

### 2. Arena — ลงมือปฏิบัติ

สนามแห่งการลงมือปฏิบัติอย่างง่าย หลังเรียน concept พื้นฐานแล้ว:

| หัวข้อ | รายละเอียด |
|--------|------------|
| **Visual Coding** | พัฒนาโค้ดด้วยบล็อกกราฟิกแบบ Drag-and-Drop ลด Syntax Error ฝึก Algorithmic Thinking |
| **Simulation** | สภาพแวดล้อมดิจิทัลที่ทำงานร่วมกับ Physics Engine ทดสอบ/ทำนาย/แสดงปฏิกิริยาของระบบฝังตัวภายใต้เงื่อนไขอวกาศจำลอง |

### 3. Studio — สร้างสรรค์ต่อ

พื้นที่หลังจากผู้เรียนสร้างเทคโนโลยี (เช่น ดาวเทียม) และทดสอบจำลองเรียบร้อยแล้ว:

- เก็บผลงานในพอร์ตโฟลิโอ
- วางแผนพัฒนาต่อ ไอเดียต่อยอด
- **LAIKA** — AI ให้คำแนะนำ shape ปัญหา/ไอเดียให้สอดคล้องฟิสิกส์ วิเคราะห์คุณค่าแนวคิด นำไปสู่นวัตกรรมหรือเส้นทางอาชีพ

เทคโนโลยี AI ใน Studio:

| ส่วน | บทบาท |
|------|--------|
| **LAIKA** | AI ที่ปรึกษา — แนะนำภารกิจ/แนวคิดที่ผู้เรียนสร้าง ช่วยพัฒนาต่อ |
| **LLM** | ประมวลผลภาษาธรรมชาติจากการฝึกฝนด้วยข้อมูลมหาศาล |
| **RAG** | ดึงข้อมูลจากคลังความรู้ภายนอก (วิศวกรรมอวกาศ, เอกสาร NASA) ก่อนตอบ — ลด Hallucination ให้คำแนะนำตรงตามหลักวิชาการ |

## การแมปกับ Landing Page (ปัจจุบัน)

Landing page ใช้ชื่อนำเสนอ **LEARN / BUILD / LAUNCH** ใน `PlatformSection.tsx` ซึ่งสอดคล้องกับ product model ดังนี้:

| Landing (UI) | Product (canonical) | บทบาท |
|--------------|---------------------|--------|
| LEARN (เรียนรู้) | **Space** | ปูพื้นฐาน 4 หัวข้อ |
| BUILD (สร้าง) | **Arena** | Visual coding + Simulation |
| LAUNCH (ปล่อย) | **Studio** | พอร์ตโฟลิโอ, LAIKA, ต่อยอดไอเดีย |

เมื่อพัฒนาฟีเจอร์ใหม่ ให้ใช้ **Space / Arena / Studio** เป็นชื่อ product หลัก; ปรับ UI ให้สอดคล้องเมื่อมีโอกาส
